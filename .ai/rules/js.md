# Js

## Inertia Vue frontend
Build application screens as Inertia Vue pages and use the existing Vue layouts and components.

## Use Wayfinder actions for form submissions
Import controller actions from `@/actions` for Inertia form submissions (for example `form.post(store().url)`). Use named route helpers from `@/routes` only for navigation links and non-controller route destinations.
